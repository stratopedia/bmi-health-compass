# BMI Health Compass V2

Technology

The design can be built entirely with:

* React
* TypeScript
* Tailwind CSS


1. Prerequisites

Install:

Node.js (LTS)
npm (comes with Node.js)

To check the versions:
node -v
npm -v

2. Install Dependencies

> npm install

3. Start Development Server

> npm run dev

4. Open Browser

> Navigate to: http://localhost:5173
